# wicket — core concepts

The canonical copy of this document is the Claude Doc **"wicket — core concepts"**:
https://claude.ai/artifact/AATnju2Q7j6j2TvpCJ8XuP

It covers what wicket is, the concepts and how they relate, the agent lifecycle, and a one-task
walkthrough, with two diagrams. It is exported here as Markdown whenever the repository is published.
The detailed design is [design.md](design.md). An earlier local draft is kept at
`research/.concepts-v0-local-draft.md` for reference; it predates platform mode, cross-tenant sharing,
long-lived agents and crews.
