---
area: Manifests
type: Changed
---
- A manifest names its agent's harness as `agent.harness` (`claude-code` or `acp`), not
  `agent.kind`, so `kind` means only `spawn`'s workload type (`agent` or `program`). There is no
  alias: `agent.kind` is now an unknown field. Remote Control (`agent.remote`) and `wicket wrap` are
  the harness's remote and wrapped modes, and a harness whose adapter hasn't the mode refuses it.
  `run.start` records `kind` as `agent` or `program`, and the harness as `harness`
  ([#255](https://github.com/public/wicket/issues/255)).
- What is Claude's (the `claude-oauth` login and `api.anthropic.com` for wrapped sessions, the
  `state/claude` config directory and its settings file, the `claude` processes hibernation counts as
  the runtime, the default agent image name) is in the Claude adapter, behind the one harness adapter
  interface the runner, the node and hibernation call
  ([#255](https://github.com/public/wicket/issues/255)).
