- `wicket self update` takes a build more than one protocol version ahead when every active enrolled
  node moves with it (`--nodes`). The nodes switch before the control host hands its runs over, the
  health gate checks them all, and a failed gate switches them all back. A jump that would leave a
  node behind is refused, naming the nodes. A rollback across such a jump follows the same rule
  ([#207](https://github.com/public/wicket/issues/207)).
