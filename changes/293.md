- A run ends when its agent calls `finish` even if its harness lingers afterwards (a background
  process of its keeps it waiting, say). Once the turn has ended and the session is closed, the
  harness gets the zone's new `limits.exit_grace` (default 30 s) to exit; then wicket stops what is
  left, syncs the workspace back, and records the run as succeeded with a note naming the processes
  it stopped. Without `finish`, the harness still decides. `hibernate` in a box where other
  processes still run no longer leaves the agent running: after the same grace wicket stops them,
  names them in `wicket agents`, and hibernates it
  ([#293](https://github.com/public/wicket/issues/293)).
