---
area: Long-lived agents
type: Fixed
---
- A long-lived agent whose run is lost no longer stays `active` with nothing behind it. When the
  reconciler ends the run as `lost`, or a re-attach fails, the agent ends with it: it goes back to
  `hibernated` (wakeable from its last hibernation) if it has hibernated before, and to `ended`
  otherwise, with a note saying why ([#474](https://github.com/public/wicket/issues/474)).
