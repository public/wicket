- A node finds a run's files by their path, not only by its box record, so `wicket node forget
  <run> --force` deletes a run directory the node no longer has a record for (a box that exited
  uncollected before the node restarted). The node reports such directories, with their sizes, in
  its health and `wicket node top` (alert `<node>/orphaned`), and the deletion is audited
  (`run.files_deleted` with `orphaned`) ([#449](https://github.com/public/wicket/issues/449)).
