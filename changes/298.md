area: Secrets
type: Fixed
---
- `wicket secret link` keeps a Claude login's non-secret account fields (its `oauthAccount` from
  `~/.claude.json`, without the holder's name) with the secret, and re-reads them at each re-link.
  Remote Control boxes start from that copy and no longer read `~/.claude.json`, whose ACL Claude Code
  drops when it replaces the file, so they no longer fail with "Unable to determine your organization
  for Remote Control eligibility". A link that can't read the file still links, and says Remote
  Control needs a re-link ([#298](https://github.com/public/wicket/issues/298)).
- `examples/remote-control-box.yaml` reaches the session endpoints current Claude Code's Remote
  Control calls (`POST /api/oauth/validate`, `POST /v1/sessions` and the session's own events,
  state and archive, reconnecting and deregistering its environment), so a box starts with nothing
  pending ([#298](https://github.com/public/wicket/issues/298)).
