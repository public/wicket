- `request_capacity`'s `region` must be a provider's region name (1 to 32 lowercase letters, digits
  and hyphens): it was written into the request's terms as sent, so a region could read as other
  terms. The agent's reason and region are kept as its claims, for the console to quote as its own.
  On a spawn's approval card, and in what a spawn beyond its parent exceeds, every value the agent
  chose that isn't one plain token (a host, a glob, a method) is quoted, so none reads as the card's
  own terms ([#731](https://github.com/public/wicket/issues/731)).
