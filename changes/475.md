- A run that outlives an install keeps its prompts. At its start, `wicketd` moves each run whose
  supervisor still runs an older build to the installed one: that supervisor is stopped without its
  box, and the new build's reconciler starts one that re-attaches. Before this, an older supervisor
  dropped the prompts a newer schema wrote ([#475](https://github.com/public/wicket/issues/475)).
